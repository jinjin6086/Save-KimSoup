# 김스프를 구해라

공격을 발차기로 반사하며 김스프를 구하러 떠나는 Windows 횡스크롤 액션 게임입니다. 최신 개발 내용은 **승쿠런 1.17**이며, 현재 GitHub 공개 실행 ZIP은 **1.16**입니다.

프로젝트 노션: [김스프를 구해라](https://app.notion.com/p/38f8d2ee0ba8808da5ced14b4ece60f3)

## 바로 플레이하기

**[GitHub 공개 실행용 ZIP: 승쿠런 1.16](https://github.com/jinjin6086/Save-KimSoup/releases/tag/v1.16)**

1. 릴리스 **Assets**의 `1.16.zip` 전체를 압축 해제하고 `승쿠런 1.16 버전.exe`를 실행합니다.
2. `Assets` 폴더를 실행파일과 함께 두세요. Windows x64용이며 별도 .NET 설치가 필요하지 않습니다.
3. 자동 생성 `Source code` ZIP은 플레이용이 아닙니다.

**1.17 배포 상태:** 소스는 저장소에 반영되어 있지만 GitHub 릴리스는 실행 ZIP이 없는 초안입니다. 이번 작업에서 만든 **1.17 재구성 실행본**은 제작자에게 작업 대화에서 전달했습니다. [전체 변경 내역·파일 정보·검증 범위](release/1.17-recovery.md)를 확인하세요.

## 소스와 빌드

소스는 [`src/CookieRunVS2026`](src/CookieRunVS2026)에 있습니다. Windows와 **.NET 10 SDK / Windows Forms 개발 환경**이 필요합니다.

이미지·음원은 실행용 ZIP의 `Assets`를 `src/CookieRunVS2026/Assets`로 복사해 사용합니다. 1.16 ZIP만으로 빌드하면 1.17에서 추가된 일부 이미지·음악이 빠집니다. 재구성 1.17 ZIP에는 해당 자원이 들어 있습니다. [기존 집컴 1.17 자원 목록](release/runtime-assets.json)과 재구성본 ZIP 안 `자원 목록.json`은 서로 다른 빌드의 목록입니다.

```powershell
dotnet build src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
dotnet run --project src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
```
