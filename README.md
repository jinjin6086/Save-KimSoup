# 김스프를 구해라

공격을 발차기로 반사하며 김스프를 구하러 떠나는 Windows 횡스크롤 액션 게임입니다. 현재 배포는 **승쿠런 1.17 버전**입니다.

## 바로 플레이하기

**[승쿠런 1.17 버전 다운로드](https://github.com/jinjin6086/Save-KimSoup/releases/tag/v1.17)**

1. 릴리스 **Assets**의 실행용 ZIP을 받습니다. 자동 생성 `Source code` ZIP은 플레이용이 아닙니다.
2. 전체 압축을 풀고 `승쿠런 1.17 버전/승쿠런 1.17 버전.exe`를 실행합니다.
3. `Assets` 폴더를 실행파일과 함께 두세요. Windows x64용이며 .NET 런타임이 포함되어 있습니다.

## 1.17 업데이트


- 고해상도 로비 플레이어와 주먹을 쥐는 결의·호흡 동작.
- 스테이지 전환 시 완전히 달려 나간 뒤 다음 장소로 자연스럽게 진입.
- 납치 오프닝의 음산한 음악, 기상 시 아침 배경, 인물별 대화 효과음.
- 이상진 W/E 시계 리듬 판정 강화, 피격 후 자동 무적 제거, 메테오 발차기 판정 완화.
- 강로디언 QTE 거리 확대·더 높은 공중 배치. 일반 레이저 너비는 1/3.
- QTE 새 독백과 땀, 어두운 성악·오케스트라에서 반격 시 비장하게 고조되는 새 음악.
- QTE 실제 입력은 기존 10초·SPACE 70회. 읽는 독백 구간은 12초.
- 이상진 HP25 / 파괴옥 HP30·15 피해 시 광폭화 / 강로디언 HP40·10 피해 시 멘헤라.
- 피한다: 불투명 문워크, 피격 직전 회피, 스킬 중 발차기 반사 가능.
- 다먹어주자: 드레인키스 흡혈 연출. 기존 수치·메테오 예외 유지.
- 무승부로 하지 않을래..?: HP500 미만에서 라운드당 1회, 자신의 최대 체력 50%만큼 회복. 보스 회복 삭제.
- 이판사판이다!!: 원본 최대 체력 50%, 원본 공격력 150%, 초록 아우라.
- 패시브 공백 카드 삭제. 5개 모두 선택 가능.
- 강로디언 대사 ‘풀어줘서 고마워...’ 적용.


1.16의 납치 오프닝, 보스 대화, 라운드별 장소 진입, 김스프 구조·식사 엔딩은 유지했습니다. [이전 1.16 릴리스](https://github.com/jinjin6086/Save-KimSoup/releases/tag/v1.16)도 그대로 받을 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ↑ / ↓ | 점프 / 슬라이딩 |
| SPACE / SHIFT | 발차기로 공격 반사 |
| Q | 선택한 능력 |
| W / E | 이상진 시간정지 시계 리듬 |
| SPACE 연타 | 강로디언 최후발악 QTE, 10초·70회 |
| ENTER / SPACE / 클릭 | 대사 표시 및 다음 대사 |
| P / M / T(로비) | 일시정지 / 소리 / 연습 모드 |
| ESC | 종료, 연습 중에는 연습 설정으로 돌아가기 |

## 소스와 빌드

소스는 [`src/CookieRunVS2026`](src/CookieRunVS2026)에 있습니다. Windows와 **.NET 10 SDK / Windows Forms 개발 환경**이 필요합니다.

큰 이미지·음원은 실행용 릴리스 ZIP에 포함되어 있습니다. 빌드할 때 **1.17 ZIP**의 `Assets`를 `src/CookieRunVS2026/Assets`로 복사하세요. [자원 목록과 SHA-256](release/runtime-assets.json).

```powershell
dotnet build src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
dotnet run --project src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
```
