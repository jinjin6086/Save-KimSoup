## 1.18 수정 내용

- 이상진 체력15, W/E 랜덤6박자·기존2배속·판정±8프레임. 실패3,000·성공 보스1 유지. 적 시간가속1.3배/15초 주기/4초 지속, 플레이어 속도 유지.
- 파괴옥 체력20/남은10 이하 광폭화, 메테오 적중마다350~700(기본·늑대·클론 동일). 넓은 반사와 위로 반사 유지.
- 강로디언 체력40/남은20 이하 멘헤라. 탈·덕·안·돼! 네 음절과 마지막 게이지 동안 실제로 다가오는 밝은 레이저. 금색 실제 사각형에 닿을 때 반사, 도착 전 피해0, 실패 시2,000 한 번. 연속 레이저·흡수·회피·반격·쿨타임 초기화 유지.
- 아주 연한 금색으로 실제 발차기 범위 상시 표시. 첫 라운드 손 배치·점프·2단 점프·슬라이딩·반사·Q 실습, 피해/진행/클리어 시계 정지, 실패 재시도, 임시 Q 복구, ENTER 스킵. 별도 연습 모드 제외.
- S 스토리 스킵과 보상 유지. 로비 중간 손 키프레임과 원본 이미지 비율 복원.
- 최후발악 QTE는10초/SPACE70회 및 기존 GPU 연출·음악 유지.
