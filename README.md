# 김스프를 구해라

공격을 발차기로 반사하며 김스프를 구하러 떠나는 Windows 횡스크롤 액션 게임입니다. 현재 배포는 **승쿠런 1.16 버전**입니다.

## 바로 플레이하기

**[승쿠런 1.16 버전 다운로드](https://github.com/jinjin6086/Save-KimSoup/releases/tag/v1.16)**

1. 릴리스의 **Assets**에서 실행용 ZIP을 받습니다. 자동 생성 `Source code` ZIP은 실행용이 아닙니다.
2. 전체 압축을 풀고 `승쿠런 1.16 버전/승쿠런 1.16 버전.exe`를 실행합니다.
3. `Assets` 폴더를 실행파일과 함께 두세요. Windows x64용이며 .NET 런타임이 포함되어 있습니다.

## 1.16 업데이트

- 이상진이 잠든 김스프를 데려가는 오프닝. 플레이어는 빈자리와 ‘잘 쓸게요~’ 쪽지, 뒷면의 마왕성 주소를 확인하고 출발합니다.
- 초원 → 성문과 감옥 → 화산 → 지하감옥 앞 황폐한 공연장 → 구출 장소로 이어지는 입장 컷신.
- 보스전 시작·광폭화·멘헤라·처치 직전·QTE 독백·구출·식사 대사를 새 스토리로 연결했습니다.
- **강로디언 QTE는 10초 동안 SPACE 70회.** 69회는 성공하지 않으며, 누르고 있는 자동 반복은 세지 않습니다.
- 네 문장의 QTE 독백을 읽을 수 있도록 독백만 8초로 조정. 반격 이후 음악·연타·폭발의 연결은 유지했습니다.
- 최신 강로디언 리듬 리메이크 BGM 포함. 기존 GPU VFX, 다른 전투 규칙, 스킬 선택·강화, 선택형 종결보스와 117개 효과음 유지.
- 스토리 중 전투와 클리어 시간은 정지합니다. P 일시정지, 창 전환 시 정지를 지원합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ↑ / ↓ | 점프 / 슬라이딩 |
| SPACE / SHIFT | 발차기로 공격 반사 |
| Q | 선택한 능력 |
| W / E | 이상진 시간정지 시계 리듬 |
| SPACE 연타 | 강로디언 최후발악 QTE |
| ENTER / SPACE / 클릭 | 대사 표시 및 다음 대사 |
| P / M / T(로비) | 일시정지 / 소리 / 연습 모드 |

## 소스와 빌드

소스는 [`src/CookieRunVS2026`](src/CookieRunVS2026)에 있습니다. **Windows와 .NET 10 SDK / Windows Forms 개발 환경**이 필요합니다.

큰 이미지·음원은 릴리스 실행용 ZIP에 포함되어 있습니다. 빌드할 때 해당 ZIP의 `Assets`를 `src/CookieRunVS2026/Assets`로 복사하세요. 같은 버전의 자원을 사용해야 합니다. [자원 목록과 SHA-256](release/runtime-assets.json).

```powershell
dotnet build src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
dotnet run --project src/CookieRunVS2026/CookieRunVS2026.csproj -c Release
```
