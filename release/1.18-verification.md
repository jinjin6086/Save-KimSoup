# 1.18 검증 결과

- 빌드: Windows x64 자체 포함 publish 성공. 게임 프로젝트 경고0/오류0. 공식 NuGet 재확인 완료.
- 동작: 실제 게임 메서드와 입력을 사용하는 자동 검사150개 통과. HP15/20/40, 변신 경계와 건너뛰는 피해, ±8프레임 입력 경계, 가속15초/4초/1.3배, 네 캐릭터 상태의 메테오350~700과 실제 피격, 위로 반사, 레이저 실제 접근·조기피해없음·한 번2000·반사·쿨타임·흡수·회피·쿠나이 미전환, 튜토리얼 입력·실패 재시도·성공 귀환·ENTER·Q 임시복구·시계정지, S 스킵과 보상, 기존QTE10초70회 성공 및 후속 화면.
- 시각: 로비 세 키프레임, 금색 실제 범위, 안내 글자, 이동하는 밝은 레이저 앞부분 렌더 이미지 확인. 안내와 기존 배너 겹침 수정.
- GPU: 하드웨어 QTE 주요10장면 생성, 성공 후 GPU 종료와 기존 후속 화면 복귀 확인.
- Windows 실행: ZIP에 들어간 EXE와 같은 해시의1.18.0.0 실행파일을 직접 시작해 로비 표시 확인. 전구간 사람 손 플레이는 미실시.
- 자원/압축: 원본 Assets99개 파일별SHA-256 동일. ZIP CRC와 모든 내부 파일 해시 확인. 번들 안 게임 DLL이 이번win-x64 빌드와 동일하고 .NET10.0.12·WindowsDesktop10.0.12 포함 확인.
- 외부 반영: 노션의 수치·레이저·튜토리얼·S 스킵 갱신. GitHub 릴리스 ZIP 첨부는 저장된 브라우저 접근 차단으로 미완료. 원격 업로드 파일의 EXE 검증도 업로드가 이루어지기 전에는 완료로 간주하지 않음.
