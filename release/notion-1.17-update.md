## 01. 게임 소개 — 버전·다운로드 안내 교체

**현재 개발·재구성 실행본 — 승쿠런 1.17 / GitHub 공개 실행본 — 승쿠런 1.16**

1.17 코드는 GitHub에 반영되어 있습니다. GitHub의 1.17 릴리스는 실행 ZIP 첨부가 없는 초안 상태이며, 현재 공개 다운로드할 수 있는 기존 실행본은 [1.16](https://github.com/jinjin6086/Save-KimSoup/releases/tag/v1.16)입니다.

이번 재구성 1.17 실행 ZIP은 제작자에게 작업 대화에서 전달했습니다. 집컴의 새 이미지·음원 원본을 확보하지 못해 일부 자원을 기존 1.16 자료를 바탕으로 새로 구성했습니다. 집컴의 1.17 자원 원본과 완전히 동일하지 않습니다.

로비에는 고화질 플레이어와 주먹을 쥐는 결의 동작, 이후 호흡 모션이 적용됩니다. 재구성 빌드는 손을 쥐는 중간 프레임 누락과 원본 이미지 비율 왜곡도 수정했습니다.

## 02. 시스템 소개 — 해당 항목 갱신

### 발차기와 회피

기존의 기본 발차기 재사용 시간 1초와 보스 적중 시 최대 체력 5% 회복 설명은 유지합니다. 일반 피격 후 자동 무적은 제거되었으며, 메테오는 발차기 반사 판정 여유가 넓어지고 빠른 이동 경로도 검사합니다. 이상진 W/E 리듬 판정도 보강했습니다.

### 라운드와 성장

기존 문구 ‘2라운드 클리어 — 사용 가능한 패시브 5종 중 하나를 직접 선택. 별도 슬롯 1개는 공백’을 다음으로 교체합니다.

**2라운드 클리어 — 패시브 5종 중 하나를 직접 선택. 공백 카드는 선택 목록에서 제외했습니다.**

기존 1·3·4라운드 보상과 강화·기록·연습 설명은 유지합니다.

### QTE — 강로디언과 최후의 레이저 맞대결

플레이어와 보스의 거리를 넓히고 보스를 더 높은 공중에 배치했습니다. 새 독백과 땀 연출이 들어가며, 어두운 성악·오케스트라에서 반격과 함께 음악이 고조됩니다. 독백을 읽는 구간만 12초입니다. 실제 QTE 입력은 기존과 같이 **10초 동안 SPACE 70회**이며, 키를 누르고 있을 때의 자동 반복은 인정하지 않습니다. 일반 전투 레이저의 너비는 기존의 1/3입니다.

기존 성공·실패 분기 설명은 유지합니다.

## 재구성한 이미지와 음원

집컴에서 제작했던 새 자원 원본을 확보하지 못했으므로 아래 파일은 동일 원본의 복구본이 아닙니다. 제공된 1.16 자원과 공개 CC0 악기·성악 샘플을 바탕으로 새로 구성했습니다.

- 로비: `LobbyResolveMotion3.png`, `LobbyResolveOpenHD.png`, `LobbyResolveClosedHD.png`.
- 문워크: `PlayerMoonwalk6.png`.
- 아침 배경: `StoryBedroomMorning.png`.
- 음악: 납치 오프닝 `score-14.pcm`, QTE 어두운 구간 `score-10.pcm`, 반격 구간 `score-9.pcm`과 해당 메타데이터.
- 음원 출처와 변경 내용: ZIP 안 `Assets/Audio/RECOVERY-1.17-CREDITS.txt`.

로비 소스에서는 부분적으로 쥔 손을 표시해야 할 가운데 프레임에 완전히 쥔 HD 이미지를 사용하던 문제를 수정했습니다. 세 포즈를 각 이미지의 원래 비율로 동일한 캔버스에 맞춰 그립니다.

## 실행

1. `SeungKuRun-1.17-Windows-x64.zip` 전체를 새 폴더에 압축 해제합니다.
2. `승쿠런 1.17 버전/승쿠런 1.17 버전.exe`를 실행합니다.
3. `Assets` 폴더는 실행파일과 함께 보관합니다. Windows x64용이며 .NET 10 런타임을 포함하므로 별도 .NET 설치는 필요하지 않습니다.

자동 생성 Source code ZIP은 실행용이 아닙니다.
