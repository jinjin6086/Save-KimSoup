# 김스프를 구해라! · 승쿠런 1.18 버전

김스프를 구하러 초원, 감옥, 화산, 황폐한 공연장을 달리는 Windows 2D 액션 게임입니다. 장애물을 피하고 보스의 공격을 발차기로 반사하세요. 4라운드 후 종결 보스에 도전할지는 직접 고릅니다.

## 실행

플레이용 `승쿠런 1.18 버전.zip`을 모두 압축 해제한 뒤 `승쿠런 1.18 버전/승쿠런 1.18 버전.exe`를 실행하세요. Windows x64 자체 포함 배포본이므로 Visual Studio나 별도의 .NET 설치가 필요 없습니다. `Assets`는 EXE와 함께 두세요. 이전 버전은 별도 폴더에 보존합니다. GitHub 자동 생성 Source code ZIP은 실행용 배포본이 아닙니다.

## 조작과 첫 라운드

| 입력 | 동작 |
|---|---|
| ↑ | 점프 / 공중에서 다시 누르면 2단 점프 |
| ↓ 유지 | 슬라이딩 |
| SPACE 또는 SHIFT | 발차기로 공격 반사 |
| Q | 선택한 액티브 스킬 |
| W / E | 이상진 시간정지의 좌 / 우 리듬 입력 |
| S | 스토리·대화·이동·변신·엔딩 건너뛰기 |
| ENTER / SPACE / 클릭 | 대사 진행 |
| P / M / F | 일시정지 / 소리 / 효과 완화 |
| T (로비) | 연습 모드 |

왼손은 Q/W/E, 엄지는 SPACE, 오른손은 ↑/↓를 권장합니다. 첫 라운드에서 손 배치 → 점프 → 2단 점프 → 슬라이딩 → 반사 타이밍 → Q를 실제로 연습합니다. 앞선 동작을 익힌 뒤 최소 약 6초부터 ‘이상진의 흔적’이 등장합니다. 학습 속도에 따라 더 늦게 도달할 수 있습니다.

연습 중 라운드 진행·체력 감소·클리어 시간은 정지합니다. 검은 탄환 피해는 0이며 놓치면 다시 보냅니다. 실제 반사에 성공하면 탄환이 되돌아가는 모습을 보여줍니다. Q 단계의 ‘피한다’는 임시 대여로, 완료·건너뛰기 때 원래 스킬로 복구됩니다. ENTER로 전체 조작 연습을 건너뛸 수 있습니다. 별도 연습 모드에는 필수 튜토리얼을 넣지 않습니다.

기본 발차기는 판정 10프레임(약 0.17초), 쿨타임 1초입니다. 성공 시 쿨타임이 초기화됩니다. 실제 판정 사각형은 1픽셀의 매우 연한 금색 테두리(알파 40), 내부 알파 3으로 항상 표시되며 위치와 범위 강화에 맞춰 움직입니다. 메테오는 기존의 넓은 전용 반사 여유를 유지합니다.

S는 전투나 리듬/QTE 성공을 대신하지 않습니다. 보스 대화를 건너뛰어도 기믹 소개는 확인할 수 있으며, 다시 S를 누르면 전투로 들어갑니다. 스테이지 이동을 건너뛰어도 Q·패시브·강화 보상은 유지합니다.

## 보스 · 최종 수치

| 보스 | 체력 / 변신 | 주요 기믹 |
|---|---|---|
| 이상진 | 최대 15 | 10초마다 상하반전. 15초마다 4초간 적 공격·장애물만 1.3배 가속, 플레이어는 그대로. 시간정지 W/E 랜덤 6박자, 기존 2배속, 판정 ±8프레임(약 ±0.133초). 실패 피해 3,000 1회, 성공 보스 피해 1 |
| 파괴옥 | 최대 20 / 남은 10 이하에서 광폭화 | 메테오 적중마다 기준 700 × 50~100% = 350~700 피해. 기본·늑대·클론에 같은 범위. 느슨한 반사 판정과 위로 사라지는 반사 유지 |
| 강로디언 | 최대 40 / 남은 20 이하에서 멘헤라 | 탈·덕·안·돼! 네 음절 후 마지막 게이지 동안 레이저 앞부분이 실제로 접근. 금색 사각형에 닿는 순간 반사. 도착 전 피해 없음, 실패 도착 시 2,000 1회. 멘헤라 연속 발사도 같은 방식 |

변신 경계 아래로 한 번에 내려가도 변신합니다. 광폭화 방어·취약 초기화·기존 스킬은 유지합니다. 강로디언 레이저를 반사하면 파란 반격 레이저가 나가고 쿨타임이 초기화됩니다. 타오르는 뱃살 중에도 레이저가 쿠나이로 바뀌지 않습니다. 흡수·회피 대응도 유지합니다. 최후발악 레이저 맞대결은 별개로 **10초 / SPACE 70회**이며, 키를 누른 채 생기는 자동 반복은 세지 않습니다.
