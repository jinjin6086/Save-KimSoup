# 승쿠런 1.18 변경 내역

- 기존 1.17 릴리스·원본 프로젝트·이미지·음악을 보존하고 새 버전으로 분리.
- GitHub 기존 반영분 확인: 이상진 HP15·W/E ±8프레임·적 가속1.3배, 파괴옥 HP20·광폭화 HP10·메테오350~700, 강로디언 HP40·멘헤라 HP20, 로비 중간 손 프레임과 원본 비율.
- 일반 레이저: 탈·덕·안·돼! 전부 표시. 마지막 게이지 동안 보스→플레이어로 밝은 앞부분이 접근. 실제 금색 범위와 정확히 같은 사각형으로 이동 구간을 판정. 도착 전 피해0, 실패 시2000 한 번. 반격·쿨타임 초기화·흡수·회피 유지, 연속 발사에도 적용.
- 전투 중 판정 범위를 금색 1px/테두리 알파40/내부3으로 표시. 메테오 전용 여유 판정 유지.
- 첫 라운드: 손 배치·점프·2단 점프·슬라이딩·반사·Q 실습. 안전 상태에서 진행/체력/클리어 시계 정지. 실패 탄환 재시도, 실제 반사와 귀환, 임시 Q 복구, ENTER 전체 연습 스킵. 별도 연습 모드 제외.
- S로 오프닝·이동·보스 대화·변신·처치·엔딩 스킵. 기믹 소개와 라운드 보상 유지. 전투·시간정지 리듬·최후발악 QTE 우회 불가.
- 최후발악 QTE와 기존 연출·사운드 유지: 10초/SPACE70회.

## 검증 구분

빌드, 실제 게임 로직을 호출하는 자동 검증, 렌더 이미지 확인, Windows 배포 EXE 직접 실행을 구분해 배포 검증 기록에 남깁니다. 원본 Assets의 파일별 SHA-256을 대조하고 ZIP 내부 실행파일의 버전과 SHA-256을 확인합니다. GitHub에 실제 첨부했는지는 별도 게시 기록으로 표시하며, 로컬 ZIP 제작만으로 업로드 완료라고 하지 않습니다.
